# Живые справки — первая версия

Во время разноса на экране сами всплывают карточки:
- **термины**: композитор сказал «хроматика», и выезжает пояснение;
- **факты о треке**: их заранее готовит скрипт в таблице через OpenRouter;
- **карточка трека**: появляется, когда в таблице меняется строка «В процессе».

## Из чего состоит

| Файл | Что это | Где работает |
|---|---|---|
| `panel.html` | Пульт: распознавание речи, термины, факты, кнопки | У тебя, в Google Chrome |
| `overlay.html` | То, что видят зрители | В OBS как Browser Source 1920×1080 |
| `terms.js` | Словарь терминов (56 шт.) | Правится вручную |
| `bus.js` | Связь пульта с оверлеем (через ntfy.sh) | — |
| `apps-script/Code.gs` | Скрипт: факты + текущий трек | Отдельный проект Apps Script в твоём аккаунте |

Пульт и оверлей могут стоять на разных компьютерах. Они связываются через бесплатный сервис ntfy.sh по секретному имени «комнаты» (оно зашито в ссылку для OBS).

## 1. Скрипт (один раз, в ТВОЁМ аккаунте Google)

Скрипт отдельный: он только **читает** таблицу композитора и ничего в ней не меняет. Свои карточки он хранит в твоей собственной таблице «Живые справки — карточки», которую создаёт сам. Ключ OpenRouter лежит в твоём проекте, поэтому его никто не увидит.

1. Открой **script.google.com → Новый проект**, назови его «Живые справки».
2. Вставь `apps-script/Code.gs` вместо содержимого `Код.gs`.
3. Слева **«Сервисы» (+)** → **Google Sheets API** → «Добавить». Сервис нужен, чтобы видеть ссылки в YouTube-«чипах»; без него всё тоже работает, трек найдётся по названию.
4. **Настройки проекта (шестерёнка) → Свойства скрипта → Добавить**: `OPENROUTER_KEY` = твой ключ `sk-or-…`.
5. В редакторе выбери функцию **`checkQueue`** и нажми ▶. Разреши доступ, когда Google спросит. В журнале появится список треков, как его видит скрипт: строка, статус, название, ссылка. Проверь, что трек «В процессе» определился правильно.
6. Выбери **`setup`** → ▶. Скрипт включит триггер «раз в минуту», создаст таблицу карточек и напишет в журнал **ТОКЕН ДЛЯ ПУЛЬТА**.
7. **Развернуть → Новое развёртывание → Веб-приложение**:
   - «Выполнять от имени»: **меня**;
   - «Доступ»: **все**.
   
   Скопируй ссылку `https://script.google.com/macros/s/…/exec`.

Проверить генерацию на одном треке можно функцией `testRow`: поменяй в ней номер строки и запусти.

**Как скрипт находит текущий трек.** Он ищет на листе ячейки-легенды «В процессе» и «След трек», берёт их цвет и сравнивает с цветом ячеек в колонках A–E каждой строки. Если легенду переименуют, поправь `CURRENT_LABEL` / `NEXT_LABEL` в начале `Code.gs`.

## 2. Пульт

Открой **https://laitsberg.github.io/live-spravki/** в **Google Chrome**. Другие браузеры не умеют распознавать речь.
В настройках пульта (справа внизу) вставь ссылку на скрипт и токен.

- **«Слушать»** — включает распознавание. Услышанные термины подсвечиваются в тексте. Если включено «показывать автоматически», они сами уходят на экран: не чаще одного раза в 15 секунд, а один и тот же термин — не чаще одного раза в 15 минут.
- **«Сейчас разносим»** — трек, отмеченный «В процессе», и его факты. Факты выходят на экран только по кнопке «Показать».
- **«Выбрать трек вручную»** — запасной вариант, если строку забыли отметить.
- **Esc** убирает текущую карточку, а «Скрыть всё» ещё и очищает очередь.
- **«Проверить без микрофона»** — вводишь фразу текстом, чтобы проверить словарь.

## 3. OBS

**Источники → + → Браузер**:
- URL — ссылка из пульта («Ссылка для OBS»);
- размер 1920×1080;
- галочку «Выключать, когда не виден» лучше снять.

Кнопка **«Тестовая карточка»** в пульте проверяет связь.
Параметры ссылки:
- `pos=tl|tr|bl|br` — угол экрана;
- `scale=0.8` — масштаб;
- `sound=1` — звук «вжух» при появлении карточки;
- `debug=1` — показывать статус связи.

## 4. Как пустить звук стрима в распознавание (если оно у тебя)

Chrome слушает только микрофон, поэтому нужен виртуальный кабель:
1. Установи бесплатный **VB-Audio Virtual Cable** (vb-audio.com/Cable).
2. **Параметры Windows → Звук → Громкость приложений**: для браузера, где открыт Twitch, выбери вывод **CABLE Input**.
3. Чтобы самому тоже слышать стрим: **Панель звука → Запись → CABLE Output → Свойства → Прослушать → «Прослушивать с данного устройства»** и выбери свои наушники.
4. В пульте нажми на значок камеры/микрофона в адресной строке и выбери микрофоном **CABLE Output**.

⚠️ Если распознавание стоит у композитора, выбери его микрофон напрямую. Так точность намного выше, потому что музыка не мешает. Со звуком стрима музыка и голос смешаны, и во время проигрывания трека распознавание будет хуже.

## 5. Словарь

Словарь правится прямо в пульте: кнопка **«📖 Словарь терминов»** вверху. В нём можно:
- добавить, изменить, выключить или удалить термин;
- указать слова, на которые он срабатывает. Слова пишутся через запятую, каждое — начало слова. «!» в конце означает «только точное слово»;
- в поле «Проверить фразу» сразу увидеть, что сработает.

Словарь хранится в таблице карточек на вкладке «Термины», поэтому у всех пультов он один и тот же. При первом подключении туда автоматически заливается стандартный набор из `terms.js`. Этот файл остаётся запасным вариантом, если таблица не подключена.

## 6. Стоимость

- Факты: веб-поиск в OpenRouter (Exa) стоит около $0.007 за запрос, плюс модель (по умолчанию `google/gemini-2.5-flash:online`). Выходит около цента за трек.
- Модель можно сменить: в Apps Script → «Настройки проекта» → «Свойства скрипта» добавь `MODEL`.
- Распознавание речи в Chrome и ntfy.sh бесплатны.
